# 端到端测试指南 (End-to-End Test Guide)

本文档提供了完整的端到端测试流程，用于验证项目的所有核心功能。

## 前置条件

### 1. 环境配置

在开始测试之前，确保已完成以下配置：

#### 1.1 环境变量配置

在项目根目录创建 `.env.local` 文件：

```env
# Dify 配置 (三个不同的 API Key)
NEXT_PUBLIC_DIFY_OUTLINE_KEY=app-xxxxxxxxxxxx
NEXT_PUBLIC_DIFY_CHAPTER_KEY=app-xxxxxxxxxxxx
NEXT_PUBLIC_DIFY_LLM_KEY=app-xxxxxxxxxxxx
NEXT_PUBLIC_DIFY_BASE_URL=https://your-dify-instance.com/v1
```

#### 1.2 Dify 平台配置

在 Dify 平台上创建三个独立的 Workflow/Chatbot：

1. **大纲写作 Workflow**:
   - 类型: Workflow
   - 输入: `topic` (主题), `style` (风格)
   - 输出: JSON 结构树
   - 获取 API Key 并配置到 `NEXT_PUBLIC_DIFY_OUTLINE_KEY`

2. **正文写作 Workflow**:
   - 类型: Workflow
   - 输入: `context_summary`, `document_topic`, `section_title`, `full_outline`, `requirements`
   - 输出: Markdown 格式的章节内容（流式输出）
   - 获取 API Key 并配置到 `NEXT_PUBLIC_DIFY_CHAPTER_KEY`

3. **LLM 对话 Chatbot**:
   - 类型: Chatbot
   - 获取 API Key 并配置到 `NEXT_PUBLIC_DIFY_LLM_KEY`

### 2. 运行测试脚本

在配置完环境变量后，运行测试脚本验证 API 连接：

```bash
node scripts/test-dify-keys.js
```

预期输出：
- 所有三个 API Key 都显示"连接成功" ✅
- 如果失败，请检查 API Key 和 Base URL 配置

## 测试流程

### 测试 1: 首页大纲生成

**目标**: 验证首页能够正确生成文档大纲

**步骤**:
1. 启动开发服务器: `npm run dev`
2. 打开浏览器访问 `http://localhost:3000`
3. 在输入框中输入文档主题，例如: "2026年网络安全态势报告"
4. 点击"生成大纲"按钮
5. 等待 AI 生成大纲

**预期结果**:
- 显示加载状态
- 生成 JSON 结构树并显示在页面中
- 大纲包含层级标题（H1, H2, H3）
- 每个标题下方有"写作指导"输入框
- 可以编辑标题和写作指导

**测试点**:
- [ ] 大纲生成速度 < 30s
- [ ] 大纲结构合理（层级正确）
- [ ] 可以编辑标题
- [ ] 可以编辑写作指导

## 常见问题

### Q1: 大纲生成失败

**可能原因**:
- API Key 配置错误
- Dify 实例无法访问
- Workflow 配置不正确

**解决方法**:
1. 检查 `.env.local` 配置
2. 运行 `node scripts/test-dify-keys.js` 验证连接
3. 检查 Dify Workflow 是否已发布

### Q2: 章节生成失败

**可能原因**:
- Chapter API Key 配置错误
- Workflow 输入参数不匹配

**解决方法**:
1. 检查 `NEXT_PUBLIC_DIFY_CHAPTER_KEY`
2. 确认 Workflow 输入参数与代码一致
3. 查看 browser console 错误信息

### Q3: Word 导出失败

**可能原因**:
- 图片过大
- 服务器内存不足

**解决方法**:
1. 压缩图片大小
2. 减少文档中的图片数量
3. 检查服务器日志

### Q4: 配置无法保存

**可能原因**:
- Zustand store 配置问题

**解决方法**:
1. 检查浏览器控制台错误
2. 清除浏览器缓存
3. 重新启动开发服务器
