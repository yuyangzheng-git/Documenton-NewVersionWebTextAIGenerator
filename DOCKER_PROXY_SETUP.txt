## 🎯 配置 Docker Desktop 使用您的代理

### 步骤 1: 打开 Docker Desktop 设置

1. 点击 Docker Desktop 窗口右上角的 ⚙️ (齿轮图标)

### 步骤 2: 进入代理设置

1. 在左侧菜单中点击 "Resources" (资源)
2. 然后点击 "Proxies" (代理)

### 步骤 3: 配置代理

1. 勾选 ☑️ "Manual proxy configuration" (手动代理配置)

2. 填入以下信息：

   ┌─────────────────────────────────────────────┐
   │ Web Server (HTTP):                          │
   │   http://127.0.0.1:7890                     │
   │                                             │
   │ Secure Web Server (HTTPS):                  │
   │   http://127.0.0.1:7890                     │
   │                                             │
   │ Bypass for these hosts & domains:           │
   │   localhost,127.0.0.1                       │
   └─────────────────────────────────────────────┘

3. 如果您的代理支持 SOCKS5，也可以填入：

   SOCKS Proxy:
     socks5://127.0.0.1:7890

### 步骤 4: 应用并重启

1. 点击右下角的 "Apply & Restart" 按钮
2. 等待 Docker Desktop 重启（约 10-30 秒）

### 步骤 5: 验证配置

重启完成后，运行：

  docker info | grep -i proxy

应该能看到代理配置

## ⚠️ 重要提示

1. 确保您的代理正在运行
2. 端口号要正确（您的是 7890）
3. 配置后必须重启 Docker Desktop
4. 重启后再构建镜像

## ❓ 为什么之前失败？

之前传递的 --build-arg http_proxy=http://127.0.0.1:7890
在容器内部，127.0.0.1 指向容器自己，不是主机！

配置 Docker Desktop 代理后，Docker 会自动处理这个问题。
